# AI Agent Workflow from Mobile

Choose the AI mode based on the shape of the work. **AI Chat** helps you understand and decide; **AI Agent** can assist a sequence that spans project files, terminal checks and a final summary.

The workflow is still improving, but it is already available on Google Play. The App Store release is in progress. If remote development or SSH is part of your everyday work, try it on a real task and tell us what feels missing—specific feedback helps shape the next release.

## Use AI Chat when the answer is the next step

Ask for a code explanation, an interpretation of terminal output, a refactor outline or a review checklist. Keep the relevant file active so the assistant has the right context.

## Use AI Agent when the work has several steps

An Agent workflow may inspect files, propose a plan, make an edit, run a check and report the result. It is available during the 14-day, per-device trial and with Pro; it does not use a free usage quota.

## Keep the workflow reviewable

1. Define the outcome and the workspace boundary.
2. Inspect the plan before a write or command action.
3. Read the actual command output and changed files.
4. Run a project-appropriate verification command.
5. Inspect the Git diff before delivery; use Pro if delivery needs a gated Git write action.

NimoteCode uses validation and locking mechanisms around tool use, but production responsibility remains with the person running the workflow. Read [Security and Safety](/docs/security) and [AI Chat and Agent](/docs/ai) for setup details.
