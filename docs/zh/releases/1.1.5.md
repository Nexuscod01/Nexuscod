# NimoteCode 1.1.5

发布于 2026 年 9 月 6 日。本次更新让移动开发闭环更加完整：你可以并排编辑两个文件、直接预览 Web 项目、检查 Git 变更，并在长时间使用中获得更可靠的终端与 AI 工作体验。

::: info 发布渠道
Android 是当前公开发布渠道。iPhone 和 iPad 的公开可用状态将在[下载页面](/zh/download)公布。
:::

## 新增

- **应用内浏览器预览。** 无需离开工作区即可预览本地或远程 Web 项目，也可以从 Terminal 中的 URL 直接打开预览。
- **编辑器双栏分屏。** 支持同时查看和编辑两个文件，每个分栏都能清晰保持自己的活动标签与导航状态。
- **内置媒体预览。** 图片可以直接在编辑器中查看，支持的音频和视频也可以在应用内播放。
- **更完整的 AI 工作区。** AI Chat 会展示最近任务和工作区上下文，全局紧凑状态条让正在运行的 Agent 在切换面板后依然清晰可见。
- **可选的编辑器 AI 工具。** 可以根据自己的工作流决定是否启用 AI 工具栏。
- **开源许可证页面。** Settings 新增许可证入口，完整展示 Codex、xterm、Flutter 依赖及其他随应用分发的开源软件声明与版权归属。

## 改进

- **更可靠的远程开发。** 增强 SSH 连接稳定性，并通过连接复用减少远程命令与浏览器预览隧道的额外开销。
- **长时间使用更加流畅。** 隐藏面板会暂停不必要的工作，浏览器资源受到明确限制，并优化编辑器、搜索、终端和 AI 的高频更新。
- **更稳定的 Source Control。** 改善本地与远程状态刷新、首次提交仓库、当前工作区命令、历史颜色和 Diff 渲染。
- **更统一的界面。** 编辑器 Git、LSP 和更多操作改为锚定菜单；Search 使用更合适的移动端高度；登录、订阅、Explorer、AI 消息和深色界面细节也得到优化。
- **一致的主题层级。** Solarized Dark、Dracula 和 Monokai 现在可以清晰显示面板分隔线，与默认 Light、Dark 主题保持一致。

## 修复

- 重构移动终端文本输入链路，修复连续相同字符丢失，并确保输入法组合文本只提交一次。
- 修复 Gboard 等组合输入法可能把 `echo` 变成重复或错乱文本的问题。
- 保持实体键盘的普通字符、按键重复、Enter、Backspace、Tab、Escape、方向键和组合快捷键正常工作。
- 串行处理息屏或应用进入后台后的终端恢复，避免返回应用时重复显示多条连接信息。
- 切换面板时保持终端运行，同时仅在用户主动打开 Terminal 后启动终端。
- 修复 iOS 标题栏菜单首次点击立即关闭、需要点击第二次才能打开的问题。
- 改善连续媒体播放与浏览器弹层关闭的稳定性。
