## 开发者向 SSH 客户端应该提供什么

对编程任务，不要只看主机配置和终端：

- 一个远程 Explorer，让你浏览项目而不是逐字敲路径。
- 能让文件和改动保持在上下文中的编辑器。
- 用于真实命令、日志、测试与部署检查的终端。
- 在改动离开设备前审查结果的 Git 工具。
- 能基于当前文件和任务工作的 AI 辅助。

这些拼起来可以形成一个紧凑却负责的闭环：连接、检查、编辑、验证、审查。完整的远程工作流见 [SSH IDE 页面](/zh/ssh-ide)，面向事故的场景见[值班排障](/zh/use-cases/on-call-diagnostics)。
