# NimoteCode Pro

NimoteCode 免费版可打开项目、编辑文件、使用基础终端与 AI Chat。**Pro** 面向需要完成完整移动开发闭环的任务：可审查的 Git 交付、更深入的诊断，以及可复用的并行工作。

| 工作流 | Pro 能力 | 使用价值 |
| --- | --- | --- |
| Git 交付 | diff、暂存、提交、分支、stash、拉取/推送/获取与 Git AI | 在移动端完成聚焦改动。 |
| 并行工作 | 进阶多终端组织 | 同时保留日志、测试与服务 Shell。 |

| 高级 Tasks | 运行可复用的项目命令 | 将日常开发动作保留在项目上下文中。 |
| 自动化 | 高级筛选与并行 Tasks | 更高效地运行已建立的远程命令流程。 |
| 项目传输 | Sync / Cache | 通过明确方向与路径检查移动内容。 |

免费版仍可充分体验核心工作区：本地或 SSH 项目、编辑、终端、AI Chat、基础 Tasks，以及 Agent 和远程搜索的免费额度。

Pro 并不替代命令、diff 或 AI 结果的人工审查，尤其是在生产相关环境中。
