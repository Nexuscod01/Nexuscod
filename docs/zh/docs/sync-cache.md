# Sync 与 Cache

Sync / Cache 是用于在本地与远程工作区之间主动移动项目内容的 **Pro** 工作流。它会明确传输方向，并将目标路径限制在当前工作区边界内。

## 两个清晰方向

- **Sync**：从本地项目向远程工作区传输。
- **Cache**：将远程项目内容带回本地工作区。

传输前请阅读方向和目标路径、明确哪一份内容是权威版本，并在结束后检查记录结果。Sync / Cache 适合受控交接或离线检查，不应替代仓库正常的 Git 审查与备份策略。
