## 2026

### 版本 1.1.5 · 2026 年 9 月 6 日

本次更新新增应用内 Web 预览、编辑器双栏分屏、内置媒体查看和更完整的 AI 工作区，并重点改善 SSH 稳定性、移动终端输入、Git 工作流、内存占用与界面一致性。

[查看完整的 1.1.5 更新说明 →](/zh/releases/)

### 当前发布渠道

- **兼容性：**Android 是当前公开可用的发布渠道。iPhone 和 iPad 可用性变化会在[下载](/zh/download)公布。
- **Pro 试用：**新用户可获得按设备计算的 14 天 Pro 试用。
- **AI Provider：**AI Chat 与 Agent 使用你配置的 Provider 和 API Key（BYOK）；Provider 账户负责访问与计费。
