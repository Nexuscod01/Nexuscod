# NimoteCode Pro

NimoteCode Free lets you open projects, edit files, run a baseline terminal and use AI Chat. **Pro costs $3.99/month or $39.99/year** and is for completing the higher-leverage parts of a mobile development workflow: gated Git delivery, AI-assisted work, deeper diagnostics and multiple terminal contexts.

## What Pro adds

| Workflow | Pro capability | Typical reason to use it |
| --- | --- | --- |
| Git delivery | Gated Git write workflows, including commits, pushes and stash actions | Finish a focused change from mobile after reviewing the free status, diff and history views. |
| Parallel work | Advanced multi-terminal organization | Keep logs, tests and a service shell open together. |
| AI + search | AI Agent and remote content search | Continue using these gated workflows after the trial. |
| Code intelligence | LSP diagnostics and code actions | Navigate and address configured language-server feedback. |
| Runtime diagnosis | Debug sessions, breakpoints, stacks, variables and watches | Inspect a configured remote debug target. |
| Project movement | Sync / Cache workflows | Transfer project content with explicit direction and path checks. |

## What remains useful on Free

Free is enough to evaluate the central workflow: use Local Explorer or SSH, edit a project file, run a command, configure an AI provider, ask AI Chat for help, and create or run terminal-backed Tasks. New users receive a 14-day, per-device Pro trial to evaluate Agent, remote search and other gated workflows. AI is BYOK: your provider account controls model access and billing.

## Pick Pro when the task needs a full loop

Pro is most useful when a mobile task ends with a carefully reviewed commit, requires multiple terminal contexts, or needs configured diagnostics beyond a terminal investigation. It does not remove the need to review commands, diffs or AI suggestions—especially on production systems.
