# NimoteCode Pro

NimoteCode Free lets you open projects, edit files, run a baseline terminal and use AI Chat. **Pro** is for completing the higher-leverage parts of a mobile development workflow: reviewable Git delivery, deeper diagnostics and repeatable parallel work.

## What Pro adds

| Workflow | Pro capability | Typical reason to use it |
| --- | --- | --- |
| Git delivery | Diff review, staging, commits, branches, stash, pull/push/fetch and Git AI | Finish a focused change from mobile. |
| Parallel work | Advanced multi-terminal organization | Keep logs, tests and a service shell open together. |
| AI + search | Unlimited AI Agent runs and remote content search | Work beyond the Free usage allowance. |
| Code intelligence | LSP diagnostics and code actions | Navigate and address configured language-server feedback. |
| Runtime diagnosis | Debug sessions, breakpoints, stacks, variables and watches | Inspect a configured remote debug target. |
| Advanced tasks | Run repeatable project commands | Keep routine development work close to the project. |
| Automation | Advanced filtered and parallel task execution | Run established remote command routines more efficiently. |
| Project movement | Sync / Cache workflows | Transfer project content with explicit direction and path checks. |

## What remains useful on Free

Free is enough to evaluate the central workflow: use Local Explorer or SSH, edit a project file, run a command, configure an AI provider, ask AI Chat for help, and use the included allowance for Agent and remote search. You can also create and run basic terminal-backed Tasks.

## Pick Pro when the task needs a full loop

Pro is most useful when a mobile task ends with a carefully reviewed commit, requires multiple terminal contexts, or needs configured diagnostics beyond a terminal investigation. It does not remove the need to review commands, diffs or AI suggestions—especially on production systems.
