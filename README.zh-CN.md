## 将 Android 手机变成远程 IDE —— 随时随地免费使用

无论你的 Mac 或 Linux 开发机在家、办公室还是 VPS 上，借助 **Tailscale + NimoteCode**，Android 手机都能通过 SSH 从任意网络安全访问它；无需公网 IP、无需路由器端口映射，也不用将 SSH 直接暴露到互联网。

这不只是远程终端访问。你可以在 NimoteCode 中打开真实项目、浏览文件、编辑代码、运行测试、检查 Git diff，并在同一个移动工作区使用 AI 辅助。即使不在桌前，也能处理修复、审查和真实开发任务。

> **立即尝试：**阅读[使用 Android 作为远程 IDE：借助 Tailscale 和 NimoteCode 免费 SSH 访问 Mac 与 Linux 的分步教程](https://nimotecode.com/zh/blog/tailscale-ssh-android-mac-linux)，然后[从 Google Play 安装 NimoteCode](https://play.google.com/store/apps/details?id=com.nimote.nimotecode)。

## AI Agent 工作流：从需求到可审查的 Git 结果

给 Agent 一个产品需求，然后跟随真实开发循环：**规划 → 检查项目 → 编辑文件 → 运行检查 → 修复失败 → 审查 Git 结果**。这不是单独的 AI 聊天，而是在真实工作区中完成的 AI 编程。

## 不只是 AI 编码 Agent 的远程控制器

NimoteCode 将真正的开发工作区放进手机。你可以打开本地或 SSH 项目，检查文件、编辑代码、运行命令、审查 diff，并在一个 Android IDE 中使用 AI Agent。手机直接连接你现有的开发机、VPS 或项目，而不只是用于审批远程操作的仪表盘。

## 在真实项目中使用 AI 编程

NimoteCode 将 AI Chat 和自主编码 Agent 与验证结果所需的工具结合起来：项目文件、编辑器、终端输出、任务、诊断以及 Git 源代码管理。你可以处理本地仓库或 SSH 远程 IDE 工作流，并在交付前审查产生的 diff。

## 在终端中使用你喜爱的编码工具

在当前本地或 SSH 工作区运行配置好的命令行 AI 编码工具，包括 [Codex](https://nimotecode.com/zh/codex-from-phone)、[Claude Code](https://nimotecode.com/zh/claude-code-from-phone)、Kimi 及类似工具。对于 Codex 和 Claude Code 的移动工作流，NimoteCode 将 CLI、项目文件、终端输出与 Git 审查放在一起。它不捆绑模型订阅；请在适用时配置自己的模型提供商、账户或 BYOK 访问方式。

## 功能

- 面向远程开发的本地与 SSH 工作区
- 用于导航和编辑项目的 Explorer 与完整代码编辑器
- 用于命令、日志、测试与已配置 CLI 工具的终端
- 用于状态、diff、历史与审查工作流的 Git 源代码管理
- 面向项目上下文辅助与任务的 AI Chat 和 AI 编码 Agent
- 按工作区配置提供搜索、诊断、任务、LSP、调试及同步/缓存工作流

## 快速开始

1. [从 Google Play 安装 NimoteCode](https://play.google.com/store/apps/details?id=com.nimote.nimotecode)。
2. 打开[本地工作区或通过 SSH 连接](https://nimotecode.com/zh/docs/ssh)。
3. [编辑代码或启动 AI Agent 任务](https://nimotecode.com/zh/docs/ai)。
4. 在[终端](https://nimotecode.com/zh/docs/terminal)中运行项目或检查。
5. 在 [Git 源代码管理](https://nimotecode.com/zh/docs/source-control)中审查改动。
